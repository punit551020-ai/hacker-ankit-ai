# Contributing to Hacker Ankit AI

1. Create a branch for your change.
2. Keep Android permissions minimal and user-visible.
3. Do not add secret keys, signing keys, tracking SDKs, or hidden recording.
4. Run `./gradlew assembleDebug` and `./gradlew lint` when the Android SDK is available.
5. Open a pull request with a concise description and testing notes.
